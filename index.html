三つの観測軸

レイアウトは編集可能なグリッド、挙動はキーボード優先、背景は GPU 上の仮想光学系。それぞれ独立して差し替えられるようモジュール化しています。

視覚の連続性

WebGL2 を第一候補にし、コンテキスト喪失からの復帰とレンダースケールの自動調整で、端末差を吸収します。低負荷モードでは粒子とポストエフェクトを抑制します。

入力の短絡経路

コマンドパレットとヘルプをネイティブの dialog で実装。フォーカス移動と Esc の挙動をブラウザ標準に寄せ、補助技術との相性を優先しました。

静的オペレーション

Service Worker が同一オリジンの骨格をキャッシュ。回線が途切れてもラボの閲覧と計測表示の多くを維持できます。

リリース記録

ビジュアルとは別軸で、運用と再現性を語るためのタイムラインです。各項目は詳細を展開できます。

  1. Network Information API と Page Visibility、reduce-motion を束ね、ラボ計測を単一の更新ループに集約。GPU フレーム時間は CustomEvent で UI へ橋渡ししています。

  2. シーンを FBO に描画し、ACES 近似・ブルーム・色差を別パスで合成。inline 完了時のみスキャンラインをレイマーチ側へ逃がし、二重適用を避けています。

  3. バージョン付きキャッシュで index / styles / scripts / manifest を束ね、初回訪問後はオフラインでも同じ DOM ツリーを再現。フォントはオンライン時のみ最適化ロードのままにしています。

信号の位相

スクロール量を正規化し、カメラとノイズ位相へ写像。ユーザー操作が「連続信号」として背景に戻る設計です。

  • 001 スクロール平滑化で急変を抑制
  • 002 DPR 上限でモバイル発熱を抑制
  • 003 非表示タブでは rAF を停止
